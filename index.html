⚙️ Pengaturan permainan & Firebase

Aplikasi ini dapat diuji dalam mode lokal. Untuk sinkronisasi lintas perangkat, buat proyek Firebase dan masukkan konfigurasi Web App di bawah ini.

Penting: konfigurasi web bukan pengganti keamanan. Jangan membuka seluruh database untuk semua orang. Sebelum dipakai di kelas, atur Authentication dan Security Rules yang membatasi hak guru, peserta, dan ruang permainan. Panduan resmi: Firebase Realtime Database untuk web.
Firebase belum dikonfigurasi.

Aturan permainan saat ini

  • Individu: boleh berada di kotak yang sama. Jawaban salah mengurangi posisi 1 kotak, skor tetap.
  • Kelompok: ketika tim masuk ke kotak yang sudah ditempati tim lain, tim yang lebih dahulu menempati kotak kembali ke START; skor tetap.
  • Ular/tangga: perpindahan otomatis setelah soal diselesaikan. Guru dapat menyesuaikan posisi ular dan tangga di kode awal.
  • Tantangan: soal HOTS. Jawaban benar mendapat bonus 20 poin; jawaban salah tetap mengikuti aturan mundur mode.
  • Kesempatan: hadiah acak seperti +10 poin, maju 2 kotak, atau perlindungan ular satu kali.
  • Finish: peserta mencapai kotak 100; guru dapat memilih untuk mengakhiri permainan segera atau membiarkan peserta lain menyelesaikan.

Panduan menyiapkan Firebase

  1. Buka Firebase Console dan buat proyek baru.
  2. Tambahkan aplikasi Web (ikon </>), lalu salin konfigurasi SDK ke kolom di atas.
  3. Di menu Build, buka Realtime Database dan buat database. Catat URL database yang ditampilkan.
  4. Aktifkan Authentication (disarankan akun guru dan autentikasi peserta yang sesuai kebutuhan kelas).
  5. Atur Security Rules agar hanya guru berwenang dapat mengubah status permainan, skor, kunci jawaban, dan posisi; peserta hanya boleh mengirim jawaban untuk identitasnya sendiri.
  6. Publikasikan aplikasi melalui hosting HTTPS, lalu gunakan URL situs itu untuk kode/QR. File HTML lokal tidak dapat menjadi tujuan QR yang bisa diakses perangkat lain.
  7. Uji dengan dua perangkat sebelum dipakai di kelas. Jangan menggunakan aturan database terbuka untuk penggunaan nyata.

Dokumentasi keamanan: Security Rules · Anonymous Authentication.
